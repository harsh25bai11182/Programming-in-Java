# Project Statement

## Problem Statement

Managing student information and academic performance manually can make it difficult to maintain records, update student details, search for specific students, and calculate academic performance consistently.

The Student Management System provides a simple command-line solution for managing student records and academic information in an organized manner.

## Scope of the Project

The project focuses on managing student records through a command-line interface. It allows users to:

- Add student records
- Delete student records
- Search for students
- Update student details
- Add and update subject marks
- Display student records
- Calculate percentage and CGPA
- Assign letter grades
- Reset sample student data

The current implementation uses in-memory Java collections and does not include persistent database storage.

## Target Users

The system is intended for:

- Students
- Faculty members
- Academic administrators

## High-Level Features

- Student record management
- Student search and update
- Subject mark management
- Percentage and CGPA calculation
- Letter grade classification
- Input validation
- Interactive command-line interface
